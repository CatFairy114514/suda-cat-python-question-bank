### PY-C04-SC-058 · 单选题

<p>某程序需要遍历 1 到 5 的数字，并且跳过数字 3，不打印它。下列哪段代码最符合要求?</p>
<ul class="options"><li><strong>A.</strong> for i in range(1, 6): print(i) if i == 3: continue</li><li><strong>B.</strong> for i in range(1, 6): if i != 3: continue print(i)</li><li><strong>C.</strong> for i in range(1, 6): if i == 3: break print(i)</li><li><strong>D.</strong> for i in range(1, 6): if i == 3: continue print(i)</li></ul>
<details><summary>答案与解析</summary><ul><li>for i in range(1, 6): if i == 3: continue print(i)</li></ul><p>答案依据 · 平台公布答案</p><p>continue 的作用是结束本次循环剩余部分，直接进入下一次循环，因此当 i 等于 3 时，程序会跳过 print(i)，从而不输出 3，而 1、2、4、5 会正常打印。第 1 项使用的是 break，它会在 i==3 时直接结束整个循环，后面的 4、5 都不会输出，因此不符合“只跳过 3”的要求。第 2 项先打印再判断 continue，所以 3 已经被打印出来了，不能达到跳过 3 的效果。第 4 项的条件写反了，i 不等于 3 时就 continue，导致除 3 以外的大多数数字都被跳过，逻辑与题意相反。</p><p class="muted">原解析中的选项字母可能对应旧顺序，请以此处列出的答案原文为准。</p></details>
